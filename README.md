# Ondine Plomberie : maquette de site vitrine

Maquette de démonstration d'un site de plombier-chauffagiste à Nantes. Ondine Plomberie est une entreprise fictive : les avis, prix et numéros sont des exemples.

## Pages

- `index.html` : accueil (services, tarifs, déroulé, réalisations, marques, avis, zone, FAQ, devis).
- `mentions-legales.html` : mentions légales et données personnelles sur une même page, avec les articles de loi et un bouton « Imprimer / PDF ».
- `mentions-legales.pdf` : la même page en PDF (A4).

## Ouvrir le site

Aucune compilation : ouvrir `index.html` dans un navigateur, ou servir le dossier, par exemple avec `python3 -m http.server`.

## Ressources

- Photos : Pexels, licence libre ; détail et liens dans `PHOTOS.md`.
- Polices : Bricolage Grotesque et Instrument Sans, hébergées dans `fonts/` (SIL OFL 1.1).
- Logos de marques (`images/marques/`) : fournis par le client, marques déposées de leurs titulaires.
